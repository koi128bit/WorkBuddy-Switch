WorkBuddy Switch 1.9.3：修复长系统提示词被官方渠道校验整轮拒绝，dsh 等 Agent 客户端恢复可用。

- 超过 4 KB 的系统提示词在转发前插入零宽分隔符，官方 `11128` 渠道校验不再拦截整轮请求；模型读到的指令不变，用户、助手与工具消息保持原样。
- 仍被拒绝时在同一账号按 128 / 64 / 32 / 16 字符间隔逐级加强，最多四次；不换号、已产生输出的请求不重发，短系统提示词保持原样。
- 最近请求新增 `systemGuard` 字段记录实际使用的间隔，便于区分官方渠道拒绝与本机已处理。
- 小请求、模型目录、账号池、限流、计费口径与 1.9.2 保持一致；上游明确的 400 / 403 与业务码仍原样返回。

官方代码 11128 表示渠道校验未通过。本版处理的是系统提示词的字面扫描，官方若调整判定方式仍需另行适配，也不承诺所有第三方 Agent 请求都能获准。

提供 Mac Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 的安装包，附 SHA256SUMS.txt。

macOS 使用 ad-hoc 签名、未 Apple 公证，PKG 未签署 Developer ID Installer；Windows 尚未 Authenticode 签名。
